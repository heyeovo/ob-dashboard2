# UI 设计系统重构

## 背景
当前 UI 功能齐全但"工程味"太重——主页和设置是功能卡片平铺，像管理后台而不是"家"。需要建立统一的设计规范，支持主题切换，让界面有温度。

## 已确认的方向

### 第一步：清理硬编码（纯基建，不改视觉效果）✅ 已完成
- `globals.css` 新增 15 个语义变量：pending 四色、danger 扩展三色、digested/resolved 边框+hover 各两色、primary 扩展三色（gradient/hover-soft/light）、surface-hover、border-hover
- 13 个 tsx 文件的高频硬编码已替换为变量引用（review、memory、AutoMemoryQueue、journal、cc 系列、NavBar、BottomTabBar、SideRail、HomeToolDrawer、FilterBar、BucketDetailDrawer、page.tsx）
- globals.css 内部的 `.cc-persona-error` 硬编码也已替换
- `DESIGN.md` 已同步更新
- **剩余低频硬编码**（约 30 处，暂不动）：graph 节点类型色（三套前景/背景/文字）、breath-sim 柱状色、prompts 页配色（`#FEF3EE`/`#C86B45`/`#C0BBB5`/`#FAFAF8`/`#F7F7F5`）、journal 滚动条/hint 文字、impressions 事件圆点（`#8AA4A0`）、persona 渐变端点、import 边框（`#F5D5CB`）、BucketDetailDrawer mono 提示色、settings 成功文字色。这些语义独立且出现少，强行归并会丢掉意图，后续按需收编

### 第二步：定主题规范（需要小羊输入）
- 配色方案、字体层级、质感（磨砂/玻璃/阴影深度）、动效风格
- 小羊平时看到好看的 app/网页截图攒着，攒几张就能摸出方向
- GPT 那边出过一版长方案，可以挑重点参考

### 第三步：主题切换机制
- CSS 变量层切换：`[data-theme="xxx"]` 重写变量值
- 字体缩放：加 `--font-scale` 基数，用户拖滑条整体缩放
- 质感开关：`--glass-blur` + `--glass-opacity` 控制磨砂/玻璃效果
- 设置页加控制项

### 第四步：页面改造
- **主页**：从功能清单改成"家"——名字、装饰图案、纪念日展示、几个美观的子页面入口
- **聊天页**：进来默认加载最近活跃对话，不是空白新窗口
- **设置页**：日常用的和调参用的分层，不全露出来

### 动效方向
- 页面切换：路由间 fade/slide，不硬跳
- 列表入场：卡片交错淡入
- 点击反馈：按钮微缩弹回
- 弹窗弹簧感：spring 曲线替代匀速
- 滚动驱动动画
- 考虑引入 Framer Motion

## 现有基础
- `globals.css` 已有完整 CSS 变量体系（颜色、圆角、阴影、间距、字体、动效），第一步清理后高频颜色全部走变量
- `DESIGN.md` 文档齐全，包含所有新增变量
- 核心组件（Card/StatusBadge/TagPill）和页面级操作按钮均使用变量规范

## 已加入 CLAUDE.md 的规则
- 所有颜色/圆角/阴影必须引用 CSS 变量，禁止硬编码 hex/rgba
- 移动端优先（手机是主要使用场景）

## 聊天页独立问题
- 每次进入默认是空白新窗口，需要手动选对话才能聊——应该默认续上最近对话

## 聊天页快速微调（2026-09-03）✅ 已完成

- 保留 Assistant 正文按换行拆成多个连续气泡的聊天感，不合并段落。
- 修复一轮中夹在 thinking／工具之间的正文既出现在过程容器、又在末尾气泡重复显示的问题：正文现在在真实发生位置拆泡，末尾只显示最后一段。
- thinking 去掉状态圆点和左侧竖线，改为轻量折叠表面；工具、thinking、正文继续按真实顺序交错。iPhone Safari/PWA 不支持网页设备振动，不用视觉动画伪装触感。
- Assistant 气泡使用专用 `--chat-assistant-fill` 表面变量，取消描边和阴影，使用 14px 圆角；颜色需与页面背景保持可见层级，不能复用过淡的通用次级表面。
- 当前实时回复也按换行逐颗显现：每颗新气泡轻微淡入上移，保存完成后继续播放尚未完成的分段，不能整轮结束后一次拆出全部气泡。
- 本轮只动消息分段展示与样式；顶栏、引擎／模型／Token 收纳和开发者模式仍留给后续完整聊天页改造。
- 设置首页已增加「聊天显示」：`显示运行信息`（引擎、Provider、模型、上下文入口，默认关）和 `显示 Token 数`（总数与明细，默认开）两个独立本机全局开关；使用 `localStorage`，不进入 Haven。错误、保存状态及持久化核对不受影响。后续正式 UI 设置页只需迁移入口和外观，不改变这两个偏好的语义。
- 验收：包含 `thinking → 正文 → 工具 → 正文` 的新轮次和历史轮次均不重复；每个换行段仍独立成泡；实时轮逐颗出现；生产 build 通过。

## 工作台：文件浏览器
