# UI 设计系统重构

## 背景
当前 UI 功能齐全但"工程味"太重——主页和设置是功能卡片平铺，像管理后台而不是"家"。需要建立统一的设计规范，支持主题切换，让界面有温度。

## 已确认的方向

### 第一步：清理硬编码（纯基建，不改视觉效果）
- 全站约 60 处硬编码 hex 值需要替换为 CSS 变量
- 主要集中在：记忆库/审阅页操作按钮、图谱页节点颜色、Prompt 页、日记页、错误提示
- 缺少的语义变量需先补上（pending 黄 `#FDF3E4/#C97E2C`、error 红 `#FCEEED/#F0C0BF` 等）
- 完成后所有颜色/圆角/阴影/字体都走 `globals.css` 的 CSS 变量

### 第二步：定主题规范（需要小羊输入）
- 配色方案、字体层级、质感（磨砂/玻璃/阴影深度）、动效风格
- 小羊平时看到好看的 app/网页截图攒着，攒几张就能摸出方向
- GPT 那边出过一版长方案，可以挑重点参考

### 第三步：主题切换机制
- CSS 变量层切换：`[data-theme="xxx"]` 重写变量值
- 字体缩放：加 `--font-scale` 基数，用户拖滑条整体缩放
- 质感开关：`--glass-blur` + `--glass-opacity` 控制磨砂/玻璃效果
- 设置页加控制项

### 第四步：页面改造
- **主页**：从功能清单改成"家"——名字、装饰图案、纪念日展示、几个美观的子页面入口
- **聊天页**：进来默认加载最近活跃对话，不是空白新窗口
- **设置页**：日常用的和调参用的分层，不全露出来

### 动效方向
- 页面切换：路由间 fade/slide，不硬跳
- 列表入场：卡片交错淡入
- 点击反馈：按钮微缩弹回
- 弹窗弹簧感：spring 曲线替代匀速
- 滚动驱动动画
- 考虑引入 Framer Motion

## 现有基础
- `globals.css` 已有完整 CSS 变量体系（颜色、圆角、阴影、间距、字体、动效）
- `DESIGN.md` 文档齐全
- 核心组件（Card/StatusBadge/TagPill）用变量规范，页面级代码有散落硬编码

## 已加入 CLAUDE.md 的规则
- 所有颜色/圆角/阴影必须引用 CSS 变量，禁止硬编码 hex/rgba
- 移动端优先（手机是主要使用场景）

## 聊天页独立问题
- 每次进入默认是空白新窗口，需要手动选对话才能聊——应该默认续上最近对话

## 工作台：文件浏览器
- 当前工作台只显示改过的文件名和增减行数，无法查看内容
- 需求：在前端能浏览 VPS 上的项目文件目录和内容，手机上就能看到改了什么
- 方案：加一个 API 路由读目录/文件（复用 ccDirs 白名单安全规则），前端做树状目录 + 文件预览
- 工作台已有的"改过的文件"列表可以做成可点击，查看 diff 或完整内容
